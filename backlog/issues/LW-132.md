# LW-132: Truthful receipt vocabulary and storage-path qualification

Status: planned. Minted 2026-10-25 by the research programme (docs/51).
Milestone: M3. Priority: P1.
Dependencies: LW-124, LW-040.
Owner decision HUMAN_TODO q-47 Q2 (2026-10-25) chose Hyper-V for G5; the power-loss label below is a separate, higher claim.

## Scope
Replace the single `items_verified` receipt field with a receipt vocabulary that states the highest label its evidence supports: read back, crash-qualified (copy engine), power-loss qualified (this storage path) and archive verified at a date (ADR draft R1, docs/51 section 4.1). A receipt never uses the word "durable". The state after a publish is the named `published_unverified` state that docs/47 section 7 already defines. A power-loss label attaches to the storage-path tuple of LW-137 (ADR R6), so a different enclosure invalidates it. The copy view, the CLI and agent output show the same ladder. This item changes receipt wording and data shape only; it adds no copy capability and no effect.

## Acceptance evidence
Receipt tests: each label is produced only from its own evidence (a passing non-cached read-back is `read back` and nothing higher; a USB destination without LW-134 evidence says "not power-loss tested on this disk"); no receipt text or serialised field contains "durable"; `published_unverified` is named in receipts after a publish; a changed storage-path tuple downgrades a qualified label. Fixtures include an alternate stream named `Zone.Identifier`, which docs/51 section 2.2 asks to fold into this item. Existing refusal codes are unchanged. The copy view, CLI and agent output render the same ladder from one fixture, and no receipt reports a verified result that a fault case did not earn (docs/51 section 5 P1).

## Notes
Duplicate check: LW-124 (the approved copy-and-verify gate) and LW-040 (copy-only transactions on disposable data) own the copy behaviour these receipts describe; this item changes only what a receipt claims and the qualification it may cite, so it is not a second copy path. LW-041 owns the crash matrix that produces the evidence the labels cite. The receipt ADR (R1, docs/51 section 11) becomes an ADR when this item lands.
