# LW-127: Nice-to-have: NAS shares as granted roots

Status: planned. Minted from the owner decisions of 2026-10-12.
Milestone: MX. Priority: P2.
Dependencies: LW-004, LW-006.
Owner decision HUMAN_TODO q-38 (2026-10-12).

## Scope
Treat a NAS share as a granted root with network-volume semantics: slow, intermittently offline, no stable identity guarantees. Optional, after local-only work; take only when there is capacity.

## Acceptance evidence
Design note covering identity, offline state and watcher limits; fixture or loopback SMB evidence if built; unreachable shares shown as unavailable, never as empty.

## Boundary
No additional capability is implicitly authorised by this issue. Keep file and process mutations, elevation, cloud
transfer of personal data and public release off unless the decision above and a named safety gate say otherwise.
Synthetic data only in Git.
