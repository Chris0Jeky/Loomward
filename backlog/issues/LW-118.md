# LW-118: Build the Ask chat panel with read-only tools and citations

Status: planned. Minted from the owner decisions of 2026-10-12.
Milestone: M2. Priority: P1.
Dependencies: LW-113, LW-117, LW-058.
Owner decision HUMAN_TODO q-34 (2026-10-12); Owner decision HUMAN_TODO q-35 (2026-10-12).

## Scope
A chat panel in the app where a model can find, list and explain files, folders and apps using read-only tools over the same query surface as people and MCP agents. Answers cite the entries they came from. Anything the model suggests doing becomes a proposal the owner approves; the model has no effect or approval authority.

## Acceptance evidence
Playwright e2e on synthetic data: answers carry citations that resolve to real catalogue entries; the tool list is read-only and an attempted write or effect tool call is rejected; unknown or unindexed scope is stated; the panel works with the fake provider and a loopback stub.

## Boundary
No additional capability is implicitly authorised by this issue. Keep file and process mutations, elevation, cloud
transfer of personal data and public release off unless the decision above and a named safety gate say otherwise.
Synthetic data only in Git.
