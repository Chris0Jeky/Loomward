# LW-135: Gate the Recycle Bin retirement effect for verified archive originals

Status: planned. Minted 2026-10-25 by the research programme (docs/51).
Milestone: M4. Priority: P1.
Dependencies: LW-124, LW-037, LW-138.
Owner decision HUMAN_TODO q-48 (2026-10-25) chose the Recycle Bin after per-plan confirmation, with a human-readable ML summary.

## Scope
Gate the retirement effect for verified archive originals as one protocol: a verified copy, a re-verification after remount, a per-group review and confirmation, then the originals go to the Recycle Bin through the Shell, and only where the Shell will recycle (docs/51 section 4.4, ADR R2). The review uses the docs/49 summary for each group: what it is, its size and age, where the verified copy is and when it was last verified, hard links outside the selection that will not free space, and "H: will hold the only copy" whenever the catalogue knows no second copy (section 4.3). An item the Shell would delete permanently stops at `requires_permanent_delete_confirmation` and is never deleted by this effect. There is no permanent delete path in v1. The report's rename-into-a-retirement-area is not adopted (section 4.4).

## Acceptance evidence
Fixtures for each step: a source change, a destination identity change or a remount re-verification older than 14 days invalidates the verification (docs/51 section 4.2). An item too large for the bin, or on a volume with no bin, refuses with `requires_permanent_delete_confirmation`. The review says recycling on `C:` frees no space until the bin is emptied and shows the bin's current size. The review shows "H: will hold the only copy" when no second copy is known. Immediately before the Shell call each source's native identity and the verified copy are re-checked (a path never authorises the effect, invariant 5), and recycle eligibility is pre-checked so the Shell never falls back to a permanent-delete prompt. Crash points on the retirement step leave the source untouched or recycled, never half-removed. The effect's own gate (docs/51 section 5 P4) requires fixtures, crash points, a second independent review lens and the owner's sign-off, all recorded before the effect opens.
