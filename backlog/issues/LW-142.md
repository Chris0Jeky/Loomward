# LW-142: RAW preview catalogue with a budgeted local cache

Status: planned. Minted 2026-10-25 by the research programme (docs/51).
Milestone: M6. Priority: P1.
Dependencies: LW-099, LW-015.
Owner decisions HUMAN_TODO q-47 and q-48 (2026-10-25) bind this programme (docs/51 header).

## Scope
Build the RAW preview catalogue: browse from local derivatives, and touch originals only for original bytes (docs/51 sections 4.9 and 2.5; ADR R5). Preview extraction runs in a fixed order: embedded JPEG first, then LibRaw, then WIC, then ExifTool, with a full decode last. A two-tier local cache is keyed by volume identity and file ID, is budgeted with a hard quota and visible accounting, and never lives on `C:` while `C:` is under pressure. Placeholders are not used. LibRaw is LGPL-2.1 or CDDL C code, so it needs a legal-ip check before adoption in this AGPL project; WIC ships with Windows and needs nothing extra.

## Acceptance evidence
Once previews are cached, browsing a 100,000-item library performs zero reads on the external disk (docs/51 section 4.9). A cold 1,000-RAW import benchmark is recorded on the owner's own RAW folders (X7; real data stays out of Git). No full decode runs when an adequate embedded preview exists. The cache stays within its quota and reports its size. A cache entry is invalidated when the volume identity or file ID changes. Adopting LibRaw waits for the legal-ip check (docs/51 section 5 P5).
