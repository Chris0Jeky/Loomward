# LW-115: Design an optional elevated NTFS-metadata search helper behind its own gate

Status: planned. Minted from the owner decisions of 2026-10-12.
Milestone: MX. Priority: P2.
Dependencies: LW-113, LW-007, LW-017.
Owner decision HUMAN_TODO q-36 (2026-10-12).

## Scope
Instant whole-volume filename search from NTFS metadata through an optional elevated helper. This is a design and gate issue first: threat model, privilege separation, helper lifetime and what it may return. Implementation waits for the gate. It changes AGENTS.md invariant 2 (no elevation, no whole-disk scans); that change lands only with the gate and a separate owner-reviewed edit, never as a side effect of this issue.

## Acceptance evidence
Written threat model and gate document reviewed by the owner; a decision to proceed or not; if approved, a separate implementation issue with canaries proving the helper exposes metadata only and is not a general file reader.

## Notes
Not authorised to implement: elevation stays forbidden until the gate passes.

## Boundary
No additional capability is implicitly authorised by this issue. Keep file and process mutations, elevation, cloud
transfer of personal data and public release off unless the decision above and a named safety gate say otherwise.
Synthetic data only in Git.
