# LW-117: Define the Ask provider interface for local, cloud and bundled models

Status: planned. Minted from the owner decisions of 2026-10-12.
Milestone: M2. Priority: P1.
Dependencies: LW-017, LW-067.
Owner decision HUMAN_TODO q-35 (2026-10-12); Owner decision HUMAN_TODO q-34 (2026-10-12).

## Scope
One provider interface for the Ask model. First implementation: a local OpenAI-compatible endpoint the owner runs. Next: a cloud provider with the owner's own key, under the q-5 disclosure rules (scoped preview, names only, canaries). Later: a bundled engine. No download, key use or request without explicit consent.

## Acceptance evidence
Provider trait with a contract test suite and a fake provider; local-endpoint adapter proven against a loopback stub; every outbound request is logged with its disclosure scope; a cloud provider cannot be enabled without a consent record; keys are never written to Git or logs.
