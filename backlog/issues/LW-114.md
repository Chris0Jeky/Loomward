# LW-114: Integrate Everything as an optional whole-volume search backend

Status: planned. Minted from the owner decisions of 2026-10-12.
Milestone: M2. Priority: P1.
Dependencies: LW-113, LW-069.
Owner decision HUMAN_TODO q-36 (2026-10-12).

## Scope
Where voidtools Everything is installed, query it through its documented local interface as an optional search backend beside the Loomward index. Detect, never install or download it. Results are merged with provenance, and Everything results outside granted roots stay clearly labelled as outside the grant model.

This item owns the Everything-specific adapter qualification after LW-069's grant-scoped interface exists. Its backend can remain absent without blocking the ordinary lexical index or the MCP/Ask consumers; those items do not depend on LW-114. Do not expose this optional adapter merely because a generic or lexical projection has already passed.

## Disclosure contract (review on #422)
Everything can return names and paths outside the owner's Loomward grants. Those rows belong only to an explicit
owner-local whole-volume search mode. The shared, grant-scoped query surface used by MCP agents and the Ask model
(LW-069's adapter with LW-067 projections) excludes out-of-grant rows and their contribution to totals by default; a
broader projection needs its own explicit owner authorisation. Merged cursors and cached pages are bound to the client
and the grant epoch, so a revocation invalidates them.

## Acceptance evidence
The same query is tested as the full local owner, as an MCP client granted one root only, as a cloud Ask provider with
names-only consent, and across a revocation between list and explain: only the owner-local mode ever sees out-of-grant
rows. Detection and graceful absence verified on a host without Everything; results are labelled by source; a grant revocation hides Loomward-index results as before and the Everything boundary is stated in the UI and docs; no elevation, no installer, no network.

## Boundary
No additional capability is implicitly authorised by this issue. Keep file and process mutations, elevation, cloud
transfer of personal data and public release off unless the decision above and a named safety gate say otherwise.
Synthetic data only in Git.
