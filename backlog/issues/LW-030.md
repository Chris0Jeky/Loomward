# LW-030: Build the storage simulator and small exact oracle

Status: planned local backlog item, not a published GitHub issue.
Milestone: M2. Priority: P1.
Dependencies: LW-002, LW-009.

## Problem and deliverable
Compare the greedy baseline with exhaustive small scenarios and model intermediate copy/retention space, not just final placement.

## Proposed ownership
`experiments/tiering/; crates/loomward-core/src/planner.rs`
Read `docs/07-tiering.md` and `AGENTS.md` before implementation. Shared protocol/schema changes require coordination with their owner.

## Acceptance criteria
Feasibility is checked independently; asymmetric allocation and bandwidth budgets are covered; report cases where greedy misses a valid plan; no optimality claim is attached to heuristic results.

## Implementation and evidence
Write the failing regression or native fixture first. Implement the smallest complete interface that satisfies these criteria. Run the complete applicable Python/Rust/UI suite and the named Windows cases. Record exact commands, platform, fixture scope and results in a new evidence file. Update implementation status and the handoff checkpoint; do not call a test passed because a workflow was merely authored.

## Boundary
No additional capability is implicitly authorised by this issue. Keep unrelated file/process mutations, elevated privileges, cloud transfer and public publication off. Use only disposable data for native-effect experiments. When a required platform capability is absent, report a named limitation rather than substituting synthetic success.

## Existing baseline to extend, not recreate
The authoring pass added `experiments/reference_smoke.py` and `evidence/synthetic-experiments.json`. Its 51-case tiny exhaustive oracle exposes nine greedy feasibility misses. Preserve this counterexample, port/enlarge the oracle coverage for native physical-allocation semantics, and compare an improved bounded allocator against the baseline. This evidence does not complete the production/native acceptance criteria above.
