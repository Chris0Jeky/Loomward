# LW-129: Nice-to-have: cloud sync design (design only)

Status: planned. Minted from the owner decisions of 2026-10-12.
Milestone: MX. Priority: P2.
Dependencies: LW-092, LW-067.
Owner decision HUMAN_TODO q-38 (2026-10-12).

## Scope
Design note only for synchronising anything through a cloud service. A cloud account service is a documented non-goal of the first release (docs/02-product-spec.md, Non-goals), and no implementation is authorised. Preference-event sync is already prototyped as a simulator in LW-092; this item records what, if anything, goes beyond it.

## Acceptance evidence
A design document stating the non-goal, the options and the reasons to proceed or not; no code, no service and no account.

## Boundary
No additional capability is implicitly authorised by this issue. Keep file and process mutations, elevation, cloud
transfer of personal data and public release off unless the decision above and a named safety gate say otherwise.
Synthetic data only in Git.
