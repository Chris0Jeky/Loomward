# LW-116: Add a local semantic (embedding) search layer with consented model download

Status: planned. Minted from the owner decisions of 2026-10-12.
Milestone: M2. Priority: P2.
Dependencies: LW-113, LW-014, LW-024.
Owner decision HUMAN_TODO q-36 (2026-10-12); Owner decision HUMAN_TODO q-35 (2026-10-12).

## Scope
The driver's addition to the search stack: a local embedding index for meaning-based retrieval, evaluated against the token student (LW-024) before promotion. Embedding models download only on explicit consent (invariant 2); nothing leaves the machine. Similarity is never identity or safe-to-delete evidence (see LW-059).

## Acceptance evidence
Offline evaluation on synthetic data comparing lexical and hybrid retrieval, with calibration stated honestly; model download refused without a recorded consent; index rebuilds after a model change; unknown or unindexed content stays visible as unknown.

## Notes
Cross-reference: LW-059 (semantic and perceptual similarity) and LW-024 (embeddings versus token student).

## Boundary
No additional capability is implicitly authorised by this issue. Keep file and process mutations, elevation, cloud
transfer of personal data and public release off unless the decision above and a named safety gate say otherwise.
Synthetic data only in Git.
