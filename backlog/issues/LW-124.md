## Scope
The first real effect is copy-and-verify: copy an approved, supported file group to a new location and verify the copy. It never deletes or retires the source. It lands behind its own safety gate; AGENTS.md invariant 1 changes only with that gate, as a separate reviewed edit.

## Acceptance evidence
Design reviewed by the owner and an independent reviewer; exact consent bound to the canonical plan (LW-038); crash and fault-injection evidence from the journal (LW-039, LW-041) on disposable data; verification by content hash; source untouched in every fault case.

## Notes
Status note: design is in progress; no implementation is merged. Distinct from LW-040 (copy-only transactions on disposable data) and LW-042 (the later approved move with source retirement), which this does not enable.

## Boundary
No additional capability is implicitly authorised by this issue. Keep file and process mutations, elevation, cloud
transfer of personal data and public release off unless the decision above and a named safety gate say otherwise.
Synthetic data only in Git.
