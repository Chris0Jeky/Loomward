# LW-138: Evidence packets, multi-axis taxonomy and the coldness vector

Status: planned. Minted 2026-10-25 by the research programme (docs/51).
Milestone: M2. Priority: P1.
Dependencies: LW-110, LW-025.
Owner question Q5 (docs/51 section 9) is open: about 1,000 owner labels over a few sessions (X4); calibration claims wait for them.

## Scope
Build the deterministic evidence packet and the multi-axis taxonomy that every later categoriser stage reads (docs/51 section 4.8, stage 1; ADR R4). A packet is made per folder and holds facts only: name structure, manifest presence, sizes, last content change, last metadata change, last Git commit and dirty state inside granted project roots only, last build regeneration (newest output against newest source), coverage and confidence (docs/51 section 4.5). Labels are multi-axis (meaning, lifecycle, recreatability) and never an approval. The coldness vector is evidence fields, never one timestamp, and NTFS last-access time is reported as system-managed. Usage observation is LW-028 and the heat model is LW-029; this item only reads their outputs as fields.

## Acceptance evidence
`schemas/evidence-packet-v1.json` validates (docs/51 section 8), and synthetic packets are byte-stable for the same catalogue. The taxonomy reads packets only. Explanations render facts only, and every fact traces to a catalogue row (docs/51 section 5 P2). The coldness wording reads "no activity evidence seen since", never "unused since". A test asserts that no label field can be read as approval (invariant 3). The grouped temporal split and the macro-F1 and selective-risk reports run on synthetic plus owner labels once X4 exists.

## Notes
Duplicate check: LW-110 (the Rust student port) and LW-025 (grouped temporal evaluation and calibration) supply the evaluation and student machinery this builds on; LW-028 and LW-029 cover the activity signals this item only reads as evidence fields. Invariant 3 already forbids treating a score as approval, so the multi-axis taxonomy is distinct from any single label. Jump Lists, Recent, Prefetch and SRUM stay out (docs/51 section 4.6).

transfer of personal data and public release off unless the decision above and a named safety gate say otherwise.
