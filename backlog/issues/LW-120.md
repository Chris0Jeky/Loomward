# LW-120: Add cloud and sync awareness without triggering recall

Status: planned. Minted from the owner decisions of 2026-10-12.
Milestone: M5. Priority: P1.
Dependencies: LW-003, LW-004, LW-071.
Owner decision HUMAN_TODO q-34 (2026-10-12).

## Scope
Show OneDrive, Dropbox and Google Drive state (cloud-only placeholder, locally available, pinned, syncing) from filesystem attributes and provider metadata, without opening content. Reading metadata must never trigger a cloud recall or download. Unknown state stays unknown.

## Acceptance evidence
Windows fixture or provider-stub tests proving metadata reads do not hydrate placeholders; placeholder size versus on-disk size accounted separately; a provider that is absent or offline is shown as such; no account sign-in and no network.

## Boundary
No additional capability is implicitly authorised by this issue. Keep file and process mutations, elevation, cloud
transfer of personal data and public release off unless the decision above and a named safety gate say otherwise.
Synthetic data only in Git.
