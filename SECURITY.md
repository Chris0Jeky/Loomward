# Security and data-safety reporting

This is an observation-only research prototype, not a production file executor or backup tool. Read `docs/05-safety-security.md` for its trust boundaries and known limitations.

A public reporting address has not been established. During private testing, contact the repository owner privately and avoid posting personal data, credentials or sensitive file samples in a public issue. Before public release, configure GitHub private vulnerability reporting and publish an actual maintained contact route. Do not use an invented email address.

Do not run the reference server as administrator/SYSTEM or expose it beyond loopback. Do not point experiments at irreplaceable files, protected OS locations or live application stores. The prototype makes no same-user-malware or administrator-tamper-resistance guarantee.
